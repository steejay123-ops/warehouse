# <div dir="rtl" align="right">گزارش پیاده‌سازی چیدمان ارگونومیک ۲ ردیفه دکمه‌ها در موبایل (2-Row Ergonomic Layout)</div>

<div dir="rtl" align="right">

چیدمان دکمه‌های انتهای فرم در هر دو کارتابل **انبارگردان** و **مالی** به الگوی استاندارد ۲ ردیفه ارگونومیک ارتقا یافت.

---

### ۱. جزئیات ساختار جدید چیدمان

- **در موبایل (`< sm` / صفحه نمایش گوشی):**
  - **ردیف ۱ (اکشن اصلی):** دکمه سبز رنگ **«ثبت و ارسال به سرپرست»** با سایز بزرگ و تمام‌عرض (`w-full`) جهت کلیک سریع و بدون خطا.
  - **ردیف ۲ (اکشن‌های فرعی ۵۰/۵۰ در کنار هم):**
    - سمت راست: دکمه نیلی **«ثبت موقت»** (`flex-1`)
    - سمت چپ: دکمه خاکستری **«انصراف»** (`flex-1`)
  - **ردیف ۳ (شرطی - فقط در صورت وجود پیش‌نویس):** دکمه کم‌رنگ قرمز **«بازگشت به وضعیت قبل»** با ارتفاع بهینه (`py-3`).
- **در دسکتاپ و تبلت (`sm:` و `md:`):**
  - کلیه دکمه‌ها در یک ردیف افقی زیبا و هماهنگ (`flex-row`) در کنار هم قرار می‌گیرند.

---

### ۲. مزایای UX

1. **کاهش ۵۰٪ ارتفاع اشغال‌شده** در انتهای فرم موبایل.
2. **سلسله‌مراتب بصری شفاف** و تفکیک رنگی دقیق بین ارسال (سبز)، پیش‌نویس (نیلی)، انصراف (خاکستری) و بازگشت (قرمز).
3. **ایزولاسیون کامل و عدم دستکاری بخش‌های دیگر.**

---

### ۳. اعتبارسنجی

- اجرای `npm run build` با **Exit Code 0** تایید شد.
