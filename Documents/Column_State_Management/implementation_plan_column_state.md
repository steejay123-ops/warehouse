# مدیریت وضعیت ستون‌های جدول (Popup UI)

بر اساس بازخوردهای شما، استفاده از دکمه‌های کپسولی (Chips) لغو شد. فرایند مدیریت نماها تماماً از طریق یک **پنجره پاپ‌آپ (Modal/Dropdown)** کنترل می‌شود تا رابط کاربری شلوغ نشود. همچنین، **آخرین نمای انتخاب‌شده** ذخیره خواهد شد تا در مراجعات بعدی به صورت خودکار اعمال گردد.

## User Review Required

> [!IMPORTANT]
> **نحوه ذخیره‌سازی آخرین نمای انتخاب شده:**  
> وقتی کاربر یک نما را در پاپ‌آپ انتخاب و اعمال می‌کند، درخواستی به سرور ارسال می‌شود تا مشخص کند این نما «آخرین انتخاب» بوده است. دفعه بعد که کاربر وارد این صفحه می‌شود، جدول به طور خودکار ستون‌ها را بر اساس آن نما تنظیم می‌کند.

## Proposed Changes

---

### Backend (Django)

#### [NEW] Model & Migration
* ایجاد مدل `UserTableViewState` در اپلیکیشن `accounts`:
  * `user` (ForeignKey)
  * `table_name` (CharField)
  * `view_name` (CharField)
  * `columns_state` (JSONField)
  * `is_last_selected` (BooleanField, default=False) - برای حفظ آخرین انتخاب کاربر.

#### [NEW] API Endpoints
* **ایجاد/ویرایش/لیست نماها:** API برای مدیریت `UserTableViewState`.
* **بروزرسانی آخرین انتخاب:** هنگام کلیک روی اعمال یک نما، `is_last_selected` آن نما `True` و بقیه برای آن جدول `False` می‌شوند.

---

### Frontend (Angular)

#### [MODIFY] accounts-http.service.ts
* متدهای: `getTableViews`, `saveTableView`, `deleteTableView`, `setLastSelectedView`.

#### [MODIFY] data-table.component.ts & html
* **رابط کاربری (UI):** 
  * اضافه کردن یک دکمه «مدیریت نماها» در کنار دکمه «انتخاب ستون‌ها» (با همان سبک گرافیکی و آیکون یک چشم یا کادر).
  * با کلیک روی آن، یک پاپ‌آپ (dropdown مشابه `isColumnToggleOpen`) باز می‌شود.
* **ساختار پاپ‌آپ:**
  * در بخش بالای پاپ‌آپ: یک فیلد متنی (Input) + یک دکمه «ذخیره نمای فعلی».
  * در بخش پایین پاپ‌آپ: یک خط جداکننده و سپس لیست نماهای ذخیره‌شده.
  * جلوی هر نمای ذخیره‌شده: دکمه «اعمال» (Apply) و دکمه «حذف» (✖).
* **مدیریت State:** هنگام لود شدن جدول (در `ngOnInit`)، بررسی می‌شود که آیا نمایی با `is_last_selected=true` وجود دارد یا خیر؛ اگر بود، آن نما به جدول اعمال می‌شود.

## Verification Plan

### Manual Verification
1. مراجعه به صفحه‌ی تخصیص کالا و پنهان/آشکار کردن چند ستون.
2. کلیک روی دکمه «مدیریت نماها» و ذخیره نام «نمای ساده». بررسی اینکه در پایین لیست ظاهر شود.
3. بازنشانی ستون‌ها، سپس کلیک روی «اعمال» در کنار «نمای ساده» و بررسی اینکه ستون‌ها به حالت ذخیره‌شده درآیند.
4. خروج از صفحه و ورود مجدد (رفرش) و بررسی اینکه «نمای ساده» به طور خودکار به عنوان آخرین انتخاب، لود شود.
