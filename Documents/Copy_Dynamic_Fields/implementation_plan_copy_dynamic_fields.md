# کپی کردن فیلدهای پویا بین انبارها (Copy Dynamic Fields)

این برنامه پیاده‌سازی مربوط به ایجاد قابلیتی است که کاربران بتوانند تنظیمات فیلدهای پویای یک انبار را به صورت یکجا در یک انبار دیگر کپی کنند.

## تغییرات پیشنهادی

| بخش | مسیر فایل / تغییر | توضیحات |
|---|---|---|
| **بک‌اند** | `inventory/views.py` | افزودن `@action(methods=['post'])` به نام `copy_from_warehouse` در `ItemFieldDefinitionViewSet` برای دریافت فیلدها و کپی کردن امن در تراکنش. |
| **سرویس API** | `dynamic-field-api.service.ts` | افزودن تابع `copyFields()` جهت فراخوانی Endpoint بک‌اند. |
| **فرانت‌اند (UI)** | `dynamic-fields.html` و `dynamic-fields.ts` | افزودن دکمه «کپی از انبار دیگر»، طراحی مدال (Modal) انتخاب انبار مبدأ (از لیست `userWarehouses`) و فراخوانی سرویس برای اتمام فرآیند. |

## موارد نیازمند تایید کاربر (User Review Required)

> [!NOTE]
> در صورتی که انبار مقصد فیلدی با نام سیستمی مشابه انبار مبدأ داشته باشد، آن فیلد کپی نخواهد شد (حالت نادیده گرفتن یا Skip). این کار برای جلوگیری از بروز خطا و تداخل در دیتابیس است.
