# ستون‌های داینامیک صفحه تخصیص کالا (Dynamic Columns)

## خلاصه مسئله

در حال حاضر صفحه تخصیص کالا (`dispatch`) دارای **~30 ستون هاردکد** در HTML تمپلیت است. هر ستون با `<ng-template appTableCol="...">` ثابت تعریف شده. اگر فیلد جدیدی اضافه شود، نیاز به تغییر فرانت‌اند دستی دارد.

**هدف:** ستون‌ها از سمت **بک‌اند** تعریف شوند و فرانت‌اند **به صورت خودکار** آنها را نمایش دهد.

---

## تحلیل معماری فعلی

| لایه | وضعیت فعلی | فایل اصلی |
|------|-----------|-----------|
| **مدل بک‌اند** | `Item` (30+ فیلد ثابت) + `ItemFieldDefinition` (فیلد پویا) + `dynamic_data` (JSONField) | models.py |
| **سریالایزر** | `ItemSerializer` با `fields = '__all__'` | serializers.py |
| **API ستون‌ها** | `export_columns` → لیست فیلدها + فیلدهای پویا | views.py |
| **فرانت‌اند (دیتاتیبل)** | ستون‌ها از `@ContentChildren(TableColumnDirective)` خوانده می‌شوند | data-table.component.ts |
| **فرانت‌اند (dispatch)** | ~30 عدد `<ng-template appTableCol>` هاردکد | dispatch.html |

۱. کدام رویکرد مد نظر شماست؟
۲. آیا ستون‌های پویا نیاز به ویرایش درخطی دارند؟
۳. آیا Sort/Filter سمت سرور هم لازم است؟
۴. آیا فقط صفحه dispatch یا صفحات دیگر هم؟

- فاز ۴: فرانت‌اند — ذخیره تغییرات
