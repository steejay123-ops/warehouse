# طرح اجرایی نهایی: همگام‌سازی و یکپارچه‌سازی ناوگان و پرسنل (۴ فاز)

## اهداف و دستاوردهای محقق‌شده
1. ایجاد ۴ دسترسی مستقل و تفکیک منو به ۴ تب مجزا.
2. تقویم ماتریسی ۳۱ روزه ناوگان با پشتیبانی کامل از وب‌سوکت و ایمپورت/اکسپورت اکسل استاندارد.
3. برگه چاپی استاندارد A4 افقی با ۳ باکس امضای حقوقی.
4. پرونده رانندگان با انواع مالکیت (استیجاری، ملکی، شرکتی) و لاگ‌های ممیزی تغییرات.
5. موتور تسویه مالی ناوگان و خروجی پرداخت گروهی بانک ملی.
