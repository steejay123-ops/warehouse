# بهبود جامع سیستم پیش‌نمایش و چاپ لیبل — نسخه ۲

## پیش‌زمینه

سیستم چاپ لیبل در حال حاضر یک مودال ارائه می‌دهد که شامل پنل تنظیمات (سمت راست) و ناحیه پیش‌نمایش PDF (سمت چپ) است. بر اساس بازخوردهای کاربر، چندین مشکل و فرصت بهبود شناسایی شده است:

1. **پیش‌نمایش خودکار اجرا نمی‌شود** — کاربر مجبور است ابتدا یک تنظیم را تغییر دهد تا PDF ظاهر شود.
2. **خطای 400 در API** — ریکوئست ناقص به بک‌اند ارسال می‌شود.
3. **تنظیمات عرض و ارتفاع و سطر/ستون بی‌معنی هستند** — وقتی تمپلیت انتخاب شده، ابعاد از قبل مشخص است.
4. **توضیحات ویژه (موقت) تأثیری ندارد** — باید فیلد مربوطه روی بوم قرار گرفته باشد.
5. **نبود قابلیت انتخاب نحوه چیدمان (Collation)** — گروه‌بندی بر اساس کالا یا مجموعه‌ای.
6. **فضای تنظیمات زیاد و فضای پیش‌نمایش کم** است.
