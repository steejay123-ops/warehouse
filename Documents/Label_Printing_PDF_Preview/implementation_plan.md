# طرح پیاده‌سازی: پیش‌نمایش واقعی PDF و تنظیمات چاپ

این طرح بر اساس توافق قبلی تهیه شده است. هدف این است که در حالت «چاپ»، بوم (Canvas) طراحی با یک پیش‌نمایش واقعی و دقیق از PDF جایگزین شود و کاربر بتواند تنظیمات خاص زمان چاپ را اعمال کند.

## تغییرات پیشنهادی

### ۱. رابط کاربری (Frontend - Angular)
- **فایل‌های هدف:** `label-designer.ts` و `label-designer.html`
- **حذف بوم در چاپ:** در محیط HTML، بوم طراحی تنها در حالتی که `mode === 'settings'` است نمایش داده می‌شود.
- **نمایشگر PDF (Iframe):** اگر `mode === 'print'` باشد، بوم جای خود را به یک تگ `<iframe [src]="pdfPreviewUrl">` می‌دهد که مستقیماً PDF دریافتی از سرور را نشان خواهد داد.
- **پنل سمت راست (تنظیمات چاپ):** در حالت چاپ، یک پنل اختصاصی اضافه خواهد شد شامل:
  - لیستی از آیتم‌های انتخاب شده به همراه امکان تنظیم **تعداد چاپ (Quantity)** برای هر آیتم (پیش‌فرض ۱).
  - یک فیلد متنی برای **توضیحات لحظه‌ای (Custom Remark)**.
  - دکمه‌ای برای **به‌روزرسانی پیش‌نمایش** (صدا زدن مجدد API و آپدیت شدن iframe).
  - دکمه‌ی نهایی **دانلود / چاپ PDF**.

### ۲. سمت سرور (Backend - Django & ReportLab)
- **فایل هدف:** `label_views.py` (متد `generate_pdf`) و `label_pdf_generator.py`
- **دریافت تنظیمات جدید:** متد API تغییر می‌کند تا علاوه بر `item_ids` ساده، بتواند آرایه‌ای به شکل `[{id: 1, quantity: 2}, ...]` و فیلد `custom_remark` را دریافت کند.
- **اعمال تعداد (Quantity):** هنگام پاس دادن لیست آیتم‌ها به `LabelPdfGenerator`، هر آیتم بر اساس تعداد (Quantity) مشخص‌شده، در لیست تکرار می‌شود (مثلاً اگر تعداد ۳ باشد، آن کالا ۳ بار به کلاس ReportLab ارسال می‌شود تا ۳ لیبل برایش رسم شود).
- **اعمال توضیحات (Remark):** اگر فیلد `__custom_remark__` در لیبل قرار داده شده باشد، متنی که کاربر نوشته در آنجا چاپ می‌شود.
