# بهبود تجربه کاربری و قابلیت‌های پیشرفته سیستم چاپ لیبل (Label Printing UX Enhancements)

هدف این طرح، ارتقای چشم‌گیر بخش «چاپ لیبل هوشمند» است تا کاربران به جای درگیری با تنظیمات تکراری، یک تجربه روان، زنده و سازگار با انواع پرینترهای لیبل‌زن (از جمله Thermal Printers) داشته باشند.

## Proposed Changes

---

### بخش فرانت‌اند (Angular)

| فایل | تغییرات و توضیحات |
| :--- | :--- |
| `dispatch.ts` | حفظ منطق انتقال لیست، اما ساده‌سازی ساختار به گونه‌ای که بتوان یک "تعداد پیش‌فرض سراسری" را در دیزاینر مدیریت کرد. |
| `label-designer.ts` | - ایجاد سیستم `Debounce` (با استفاده از `Subject` یا RxJS) تا پس از تایپ یا تغییر تنظیمات، به صورت خودکار PDF بارگذاری شود.<br>- مدیریت حالت‌های جدید (سایز کاغذ، Layout، حاشیه) برای بخش Print Mode و ارسال آن‌ها به سرور بدون ذخیره قالب اصلی.<br>- نوشتن تابع جاوااسکریپتی `printPdfBlob` برای باز کردن مستقیم دیالوگ پرینت مرورگر. |
| `label-designer.html` | - افزایش سایز مودال چاپ (Full/Large) جهت نمایش بهتر پیش‌نمایش.<br>- حذف لیست آیتم‌ها در چاپ و جایگزینی با فیلد "تعداد چاپ کل" (Bulk Quantity).<br>- انتقال تنظیمات (نوع کاغذ، سایز، Landscape/Portrait) به مودال چاپ.<br>- افزودن لایه Skeleton Loading در زمان تولید زنده PDF.<br>- ایجاد دکمه **«چاپ مستقیم»** در کنار دکمه دانلود. |

---

### بخش بک‌اند (Django)

| فایل | تغییرات و توضیحات |
| :--- | :--- |
| `label_pdf_generator.py` | - اصلاح منطق رندر بر اساس نوع کاغذ (`paper_type`).<br>- اگر `roll` (حرارتی) انتخاب شده بود: `margin = 0` تنظیم شده و سایز صفحه دقیقا بر اساس `width_mm` و `height_mm` ساخته می‌شود.<br>- مدیریت بهتر خطاها در صورت جا نشدن عناصر. |
| `label_views.py` | دریافت متغیرهای موقتی از فرانت (مانند Layout، سایز دلخواه و حاشیه) در زمان درخواست تولید PDF موقت، تا تغییرات بدون ذخیره دائم قالب، روی لیبل خروجی اعمال شوند. |

## Verification Plan

> [!TIP]
> **مراحل تایید نهایی پس از اجرا:**
> 1. انتخاب چندین رکورد به صورت همزمان.
> 2. باز شدن سریع مودال به صورت بزرگ و داشتن فضای کافی پیش‌نمایش بدون نیاز به اسکرول مزاحم.
> 3. تغییر دادن نوع کاغذ به «رول حرارتی» و تنظیم ابعاد به همراه تعداد.
> 4. مشاهده پیش‌نمایش خودکار (Auto-Preview) پس از نیم ثانیه توقف در تایپ، با نمایش انیمیشن لودینگ (Skeleton).
> 5. استفاده از دکمه «چاپ مستقیم» و باز شدن بی‌دردسر پنجره پرینت ویندوز با سایز دقیق لیبل و حاشیه صفر.
