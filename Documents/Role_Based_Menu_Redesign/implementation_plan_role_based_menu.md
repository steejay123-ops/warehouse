# برنامه اجرایی جامع انتقال ۱۰۰٪ کدها و قابلیت‌ها بدون حذف (Zero-Loss Code Cloning Implementation Plan)

این طرح بر اساس اصل عدم حذف هیچ کدی، هم‌زیستی کامل و کپی مو به موی تمامی فرم‌ها، مودال‌های ۵ مرحله‌ای، توابع محاسباتی و فیلترها از کامپوننت مرجع (`personnel-management`) به ساختار ماژولار و هاب‌های تفکیک‌شده تهیه شده است.

---

## ۲. تعهدات و الزامات کلیدی (Guaranteed Invariants)

1. **عدم حذف هیچ کدی (Zero-Deletion Guarantee):** تمامی مسیرها، کامپوننت‌ها و کدهای قبلی با هم‌زیستی ۱۰۰٪ در سامانه باقی می‌مانند.
2. **کپی مستقیم منطق و عدم بازنویسی (100% Code Cloning):** فرم‌ها، متدهای فرمول‌بندی، قالب‌های HTML و استایل‌ها به صورت مستقیم کپی می‌شوند.
3. **همگام‌سازی دوطرفه آدرس مرورگر (Two-Way URL State):** تمامی تب‌ها و فیلترها با Query Params مرورگر همگام خواهند بود.

---

## ۳. فازبندی گام به گام پیاده‌سازی

- **فاز ۱:** ایجاد کامپوننت `PersonnelProfilesHub` با مودال ۵ تبِ کامل پرسنل، مودال خودرو، درون‌ریزی اکسل و ثبت در منو و روتر.
- **فاز ۲:** تکمیل کارتابل مالی (`FinanceCartable`) با مودال چاپ فیش حقوقی تکی، فیلتر دسته‌بندی پرسنل شرکتی/متفرقه و پیش‌نمایش جدول پایا.
- **فاز ۳:** تفکیک ۶ زیرتب در تنظیمات پایه (`BaseSettings`) با کپی فیلدهای کامل.
- **فاز ۴:** اجرای آزمون‌های Vitest، تست‌های بک‌اند جنگو و بررسی بیلد نهایی.
