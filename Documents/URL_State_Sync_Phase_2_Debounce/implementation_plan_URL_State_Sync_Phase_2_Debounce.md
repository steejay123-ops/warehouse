# اتصال جستجوها و فیلترهای تکمیلی به آدرس مرورگر (URL State Persistence - Phase 2)

این طرح بر اساس بازخورد شما و برای حل مشکلات پرفورمنس آپدیت شده است. 

## تغییرات ساختاری

### ۱. مکانیزم تاخیر ۲ ثانیه‌ای (Debounce)
برای کادرهای جستجو در تمامی صفحات:
- **فیلتر شدن اطلاعات در صفحه:** کاملاً به صورت **آنی (Real-time)** همزمان با تایپ کاربر انجام می‌شود تا تجربه کاربری سریع بماند.
- **آپدیت شدن URL:** با استفاده از یک `Subject` از `rxjs`، تغییرات تایپ کاربر دریافت می‌شود و تنها **۲ ثانیه (2000ms)** بعد از اینکه کاربر تایپ کردن را متوقف کرد، پارامتر `?q=` در آدرس مرورگر با متد `replaceUrl: true` آپدیت می‌شود تا History مرورگر کثیف نشود.

### ۲. جلوگیری از چرخه باطل درخواست‌ها (Infinite Loop Fix)
در داشبوردهایی که کش می‌شوند (مثل Customs و Counter Dashboard)، متد `syncTabFromUrl()` که روی `NavigationEnd` فایر می‌شود، آپدیت خواهد شد:
- قبل از صدا زدن متد `this.refreshCurrentTab()` که ریکوئست به سرور می‌فرستد، چک می‌کنیم که آیا پارامتر **تب** واقعاً تغییر کرده است؟
- اگر فقط پارامتر جستجو (`q`) تغییر کرده بود، ریکوئستی به سرور ارسال **نمی‌شود** و سیستم فقط فیلتر کلاینت‌ساید را اعمال می‌کند.

## فایل‌هایی که ویرایش خواهند شد

### ۱. کامپوننت Users (`users.ts`)
- **سرچ:** پیاده‌سازی متغیر `searchSubject` با تاخیر ۲ ثانیه برای آپدیت URL. خواندن مقدار جستجو از URL هنگام لود اولیه.
- **تب‌های داخلی:** وضعیت تب‌های داخلی شامل `activeRoleTab` (تب‌های نقش‌ها) و `activePermTab` (تب‌های مجوزها) نیز در URL به صورت `?roleTab=` و `?permTab=` ذخیره خواهند شد.

### ۲. کامپوننت Projects (`projects.ts`)
- **سرچ:** پیاده‌سازی متغیر `searchSubject` با تاخیر ۲ ثانیه برای آپدیت URL. تزریق ماژول‌های روتر و خواندن وضعیت اولیه از URL.

### ۳. کامپوننت Customs (`customs.ts`)
- **سرچ:** پیاده‌سازی `searchSubject` با تاخیر ۲ ثانیه.
- **اصلاح باگ:** جلوگیری از فراخوانی `refreshCurrentTab` اگر تغییر مسیر فقط ناشی از تغییر جستجو بوده است.

### ۴. کامپوننت Counter Dashboard (`counter-dashboard.ts`)
- **سرچ:** پیاده‌سازی `searchSubject` با تاخیر ۲ ثانیه.
- **اصلاح باگ:** جلوگیری از ریکوئست‌های تکراری با بررسی تغییر واقعی در پارامتر `tab`.

## مراحل پیاده‌سازی و تست
- ویرایش دقیق کد هر ۴ کامپوننت
- بیلد نهایی پروژه `npm run build`
- آپدیت فایل‌های مستندات `Documents` (پیرو رویه Dual-Save)
- تست زنده با تایپ در باکس جستجو، مشاهده آپدیت URL با تاخیر ۲ ثانیه و رفرش صفحه
